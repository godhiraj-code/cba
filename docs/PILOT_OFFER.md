# Starlight Protocol Pilot Offer

## Product thesis

Starlight Protocol is not just another browser automation framework.

It is a **Sentinel/Agent-powered QA reliability layer** for teams whose Playwright, Selenium, RPA, and AI-agent browser workflows are flaky, blocked by popups, leaking sensitive data, or hard to explain after failure.

The core idea:

> Decouple intent from environment.
> Let specialized Sentinels observe, veto, heal, and explain what happened.

That is the product wedge.

## Paid pilot offer

### Sentinel Reliability Audit

A fixed-scope audit that tests one high-value browser workflow or AI-agent journey.

#### Who it is for

- QA managers
- SDETs
- automation architects
- founders shipping AI agents
- teams with flaky Playwright or Selenium suites
- companies using browser automation for critical business flows

#### What the audit covers

- one high-value customer journey or internal workflow
- 50-100 scenario tests
- sentinel-based recovery analysis
- flaky failure clustering
- popup/modal/self-healing diagnostics
- PII and sensitive-data risk review
- AI-agent or browser-agent behavior checks
- final reliability report
- prioritized fix list

#### Deliverables

- HTML/PDF reliability report
- CSV/JSON test results
- Sentinel/Agent observation summary
- risk score
- top recurring failure patterns
- recommended fixes
- optional implementation roadmap

#### Suggested pricing

- India pilot: INR 25k-75k
- Global pilot: $500-$2,000
- Enterprise pilot: INR 1L-5L

## Why customers will pay

They are not paying for a tool.

They are paying for:

- fewer flaky failures
- faster release confidence
- less manual triage
- safer AI-agent behavior
- clearer root-cause analysis
- a repeatable reliability process

The buyer problem is simple:

> "Our automation works in demos, but fails unpredictably in production."

Starlight turns that pain into a measurable reliability workflow.

## Viral angle

The open-source protocol can go viral if it is easy to show, share, and extend.

Best viral hooks:

1. **Sentinel Gallery**
   - public list of community Sentinels
   - each Sentinel has a clear purpose
   - contributors can submit new ones

2. **Reliability Badge**
   - GitHub/README badge showing test stability
   - example: "Starlight Reliability: 92%"

3. **One-click demo**
   - `npm run launch:report`
   - Mission Control panel
   - visible Sentinel fleet
   - short demo video

4. **Agent + Sentinel story**
   - easy to explain
   - visual and memorable
   - strong branding
